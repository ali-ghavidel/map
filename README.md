# Iran MapLibre Project

## OpenStreetMap Data

This project uses OpenStreetMap data for Iran, provided by Geofabrik.

**Data source:** https://download.geofabrik.de/asia/iran.html

### Dataset

- File: `iran-261020.osm.pbf`
- Format: OSM PBF
- Data timestamp: 2026-10-20
- File size: 229,878,262 bytes

### Download

Download the Iran OSM dataset from Geofabrik and place it in the project root directory:

```text
C:\map\iran-261020.osm.pbf
```

The original PBF file is not committed to GitHub because it is a large source dataset.

### Purpose

The OSM dataset is used to generate vector map tiles and extract geographic data for city-wide place search.
